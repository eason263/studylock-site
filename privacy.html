English

StudyLock helps a parent keep a child's iPhone or iPad focused: apps stay locked until the child passes a short quiz, then open for a time the parent sets.

The short version

StudyLock does not collect any information about you or your child. Everything it stores stays on the device it is installed on. It has no accounts, no servers, no advertising, no analytics and no tracking, and it does not connect to the internet.

What StudyLock stores, and where

All of this is stored only on the device, inside StudyLock's own storage:

  • Settings the parent chooses: the child's level and difficulty, quiz length, subjects and topics, how long an unlock lasts, the daily limit on quiz unlock time, the app's language, and the alert thresholds.
  • The lock state: whether protection is on and when the current unlock ends.
  • Apps and websites the parent allows while locked. iOS and iPadOS give StudyLock these only as opaque tokens; StudyLock cannot read which apps they are. When the child opens a locked app, the system lets StudyLock show that app's name on the block screen; the name is not stored. StudyLock never sees how long any app is used.
  • The parent PIN, kept only as a salted, one-way hash in the device's Keychain. The PIN itself is never stored.
  • Quiz history: for each finished quiz, when it started and finished, the level and difficulty, the pass mark, whether it was passed or ran out of time, and for each question its text, subject and topic, the correct answer, and the answer the child chose or typed. It is used only to show the parent a learning report on this device. The newest 300 quizzes are kept; the file is encrypted whenever the device is locked. (If the file is ever damaged, it is kept aside on the device rather than overwritten.)
  • A short record of attempts to get around StudyLock (for example the clock being moved back during an unlock, or repeated wrong PIN entries): only the type and the time, shown only to the parent.
  • Technical records StudyLock needs to run: the quiz in progress with the answers so far; timing records that keep the lock honest (when quiz unlocks were granted and for how long, the wait after a failed quiz, the device's time zone, and an identifier the system gives each restart, so a moved clock is noticed); the identifiers of questions already asked (so they aren't repeated too soon), the wrong-PIN wait timer, the setup state and permission mode, the chosen language for quiz questions, which alerts the parent has seen, and a short diagnostic log of lock and unlock events that the parent can view.

StudyLock's developer never receives any of this. It is not sent anywhere.

Backups

Like other app data, StudyLock's data can be included in the device's own iCloud or computer backup if the device owner has turned backups on. Those backups are managed by Apple and the device owner, not by StudyLock. The parent PIN is not restored onto a different device; when StudyLock is restored onto a different device, it asks for setup again.

Screen Time

StudyLock uses Apple's Screen Time frameworks (Family Controls, Managed Settings, Device Activity) to lock and unlock apps. Permission is granted by the parent on the device. These frameworks do not give StudyLock access to the child's usage data, and StudyLock does not request it.

Notifications

StudyLock schedules notifications on the device itself, for example to say that apps will lock again soon. They are not sent from a server.

Children

StudyLock is used by children under a parent's control. It collects no personal information from children, shows no advertising, has no links out of the app for a child to follow, and has no way for a child to contact anyone.

Deleting data

Deleting StudyLock from the device deletes everything it stored, except anything already in an existing backup and, possibly, the parent PIN's hash: the system may keep Keychain items after an app is deleted. That hash is not the PIN itself, only StudyLock can read it, and it is replaced when StudyLock is set up again.

Changes

If this policy changes, the new version will be published on this page with a new effective date.

StudyLock 帮助家长让孩子的 iPhone 或 iPad 专注学习：孩子通过一次简短测验之前，App 保持锁定；通过后在家长设定的时间内开放。

简要说明

StudyLock 不收集关于你或你孩子的任何信息。它保存的所有内容都只留在安装它的这台设备上。它没有账户、没有服务器、没有广告、没有统计分析、不做任何跟踪，也不连接互联网。

StudyLock 保存什么、保存在哪里

以下内容只保存在这台设备上、StudyLock 自己的存储空间里：

  • 家长选择的设置：孩子的年级和难度、测验时长、科目和知识点、每次解锁多久、每天靠做题解锁的时长上限、App 语言，以及预警的阈值。
  • 锁定状态：保护是否开启、本次解锁何时结束。
  • 锁定期间家长允许使用的 App 和网站。系统只以无法识别的标记形式提供给 StudyLock；StudyLock 无法知道它们是哪些 App。孩子打开被锁定的 App 时，系统会让 StudyLock 在锁定页面上显示该 App 的名称，但这个名称不会被保存。StudyLock 永远看不到任何 App 被使用了多久。
  • 家长 PIN：只以加盐的单向哈希保存在设备的钥匙串中，从不保存 PIN 本身。
  • 测验记录：每次完成测验的开始和结束时间、年级和难度、及格线、是否通过或超时，以及每道题的题目、科目和知识点、正确答案和孩子选择或输入的答案。只用于在这台设备上给家长看学习报告。只保留最近 300 次测验；设备锁屏时文件是加密的。（如果文件损坏，会被另外保存在设备上，而不是被覆盖。）
  • 绕过 StudyLock 的尝试记录（例如解锁期间把时间调早、多次输错 PIN）：只记录类型和时间，只给家长看。
  • StudyLock 运行所需的技术记录：正在进行的测验和已作答的答案；防止绕过锁定的计时记录（做题解锁的时间和时长、没通过后的等待时间、设备的时区，以及系统给每次重启分配的标识，用来发现时间被调过）；已经出过的题目编号（避免太快重复）、输错 PIN 后的等待计时、设置进度和授权方式、题目语言设置、家长已查看过哪些预警，以及家长可以查看的一份简短锁定/解锁诊断日志。

StudyLock 的开发者不会收到以上任何内容，这些内容不会被发送到任何地方。

备份

和其他 App 的数据一样，如果设备主人开启了 iCloud 或电脑备份，StudyLock 的数据可能被包含在设备自己的备份中。这些备份由苹果和设备主人管理，不由 StudyLock 管理。家长 PIN 不会恢复到另一台设备上；恢复到另一台设备上时，StudyLock 会要求重新设置。

屏幕使用时间

StudyLock 使用苹果的屏幕使用时间框架（Family Controls、Managed Settings、Device Activity）来锁定和解锁 App，授权由家长在设备上完成。这些框架不会让 StudyLock 读取孩子的使用数据，StudyLock 也不会请求这些数据。

通知

StudyLock 的通知都在设备本地安排，例如提醒 App 即将重新锁定，不是从服务器发出的。

儿童

StudyLock 由孩子在家长的管理下使用。它不收集孩子的任何个人信息，不显示广告，没有供孩子点击离开 App 的链接，孩子也无法通过它联系任何人。

删除数据

从设备上删除 StudyLock，就会删除它保存的所有内容，但已存在的备份除外；另外，家长 PIN 的哈希可能仍会保留，因为系统在删除 App 后可能保留钥匙串中的条目。这个哈希不是 PIN 本身，只有 StudyLock 能读取，重新设置 StudyLock 时会被替换。

政策变更

如本政策有变更，新版本将发布在本页面，并注明新的生效日期。
